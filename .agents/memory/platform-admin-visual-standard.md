description: Approved direction for Platform Admin only; subscriber and public-site designs remain independent.

Platform Admin defaults to a light/white compact professional ERP interface, closely following
the user's supplied dashboard reference. Use white panels, a pale blue-gray page background,
navy text, orange selected navigation, blue links/actions and semantic status colours.
The sidebar groups are Overview, Customers, Billing & Access, and Platform.
Optional dark mode remains admin-local; never apply admin theme changes globally.

**Why:** The user explicitly rejected the old dark Admin appearance and asked for a full
composition/spacing/sidebar/header/table redesign, not a dark-to-white colour substitution.

**How to apply:** Future admin pages must inherit the admin visual standard without modifying
subscriber/private-public-site themes or established administrator authentication/private entry.
Use actual saved operational data. Website configuration counts are not CMS entitlement grants;
do not invent missing module metrics to resemble the example screenshot.
