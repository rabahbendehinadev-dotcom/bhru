BHRU — CUSTOMER DASHBOARD VISUAL REDESIGN

The current authenticated customer dashboard is functionally correct, but visually it feels too sparse and generic.

We want to redesign ONLY the authenticated customer panel presentation/layout.

Use DHRU Client Area as a BUSINESS LAYOUT reference only:
- strong balance visibility
- clear order overview
- announcements visible immediately
- real client-panel feeling

DO NOT clone DHRU styling.
Keep BHRU cleaner, more modern and professional.

IMPORTANT:
Do not change financial logic, authentication, routes, wallet rules, order logic, tenant isolation or account currency behavior.

This is primarily a UI/UX redesign.

==================================================
1. MAIN PROBLEM TO FIX
==================================================

Current dashboard problems:

- content container is too narrow on large desktop screens
- too much unused whitespace
- every metric card has almost the same visual importance
- available balance does not stand out
- announcements are too low on the page
- recent orders consumes too much space when empty
- authenticated header looks like a normal marketing navbar
- reseller logo is too small
- dashboard lacks icons/status visual hierarchy
- customer does not immediately feel they are inside a professional server/client panel

==================================================
2. DESKTOP LAYOUT
==================================================

Increase authenticated panel max width.

Target approximately:

1280–1440px usable dashboard width

depending on viewport.

Do not leave huge empty margins on 1600px+ screens.

Use a 12-column responsive dashboard grid.

Desktop main structure:

LEFT / MAIN AREA:
approximately 8 columns

RIGHT SIDEBAR:
approximately 4 columns

Right sidebar should contain Announcements.

Announcements must be visible without scrolling down the entire dashboard.
