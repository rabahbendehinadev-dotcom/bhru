==================================================
TARGET CURRENCY MODEL
==================================================

1. SYSTEM / ACCOUNTING BASE

USD = Base / Reference Currency.

Its rate must always be:

1 USD = 1.000000

USD is the canonical reference used for future provider/API costs and internal pricing calculations.

Do not confuse this with Client Default.

==================================================
2. SUBSCRIBER CURRENCIES
==================================================

Each subscriber can add currencies such as:

USD
DZD
EUR
GBP
etc.

Each enabled non-base currency has a MANUAL commercial exchange rate relative to USD.

Example:

USD = 1.000000
DZD = 260.000000

Meaning:

1 USD = 260 DZD

The subscriber must be able to edit this rate easily.

No external FX API.
No bank exchange rates.
No automatic rate updates for now.

==================================================
3. CLIENT DEFAULT
==================================================

Base Currency and Client Default are TWO DIFFERENT concepts.

USD may be the Base Currency while DZD can be the Client Default.

Example:

Base / Reference:
USD

Client Default:
DZD

A subscriber must be able to choose which ENABLED currency customers see by default.

Exactly one enabled currency should be Client Default.

==================================================
4. PANEL DISPLAY CURRENCY
==================================================

I also want the SUBSCRIBER PANEL to have a currency selector.

Example:

USD | DZD | EUR

If the subscriber selects USD:
prices displayed in the panel should appear in USD.

If they select DZD:
the same values should display converted to DZD using that subscriber's manual rate.

IMPORTANT:

Changing Panel Display Currency must NOT rewrite canonical stored prices.

It is a DISPLAY preference.

We need one source of truth for monetary values.

==================================================
5. PUBLIC CUSTOMER CURRENCY
==================================================

The subscriber's public storefront should also expose enabled currencies.

Initial visitor currency:
Client Default.

Customer can then select another enabled currency.

Example:

Client Default = DZD

Customer initially sees:
13,000 DZD

Customer switches to USD:
50 USD

assuming:
1 USD = 260 DZD

Changing customer currency must not alter the underlying product/service price.

==================================================

Design the architecture now so future provider APIs work correctly.
